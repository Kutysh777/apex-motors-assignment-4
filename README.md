# Apex Motors - Assignment 4

Team: Apex Motors. Group: SE-2507. Members: Arsen, Kuttibay, Farabi and Muhammad.

## Run locally

Extract the archive and open `index.html` in a browser. No installation or build is required. You can also run `python -m http.server 8000` in the project folder and open `http://localhost:8000/`.

## Assignment tasks

| Task | Location | Behavior |
| --- | --- | --- |
| 1. Form validation | `contact.html` | Required fields, valid email, password of at least eight characters and matching password confirmation. |
| 2. FAQ accordion | `services.html` | Answers are hidden initially and open or close with a smooth transition. |
| 3. Subscription popup | Footer on every page | Opens with Subscribe to Apex and closes with the close button or a click outside. |
| 4. Background color | Footer on every page | Change background cycles Warm ivory, Mist blue and Soft sage. |
| 5. Date and time | Footer on every page | A readable clock uses `Date` and updates every second. |

Shared JavaScript is in `js/main.js`. Forms demonstrate validation without sending or storing data. HTML, CSS and JavaScript contain no comments.
